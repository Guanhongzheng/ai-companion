## M2 · 长期记忆（RAG，已完成第一轮）

- [x] 记忆抽取：规则法（中文自述句式）+ LLM 抽取（有 Key 时自动切换）
- [x] 去重：余弦相似度超阈值视为重复，改为累加命中次数
- [x] 向量化：**可插拔**——本地 bge-m3 / 云端 Embedding / 哈希兜底，按环境自动选
- [x] 召回 + 重排：Top-K 召回 → bge-reranker（装了才用）→ 混合打分兜底
- [x] 记忆注入对话：新增 `memory` SSE 事件，界面展示「AI 想起了什么」
- [x] 记忆面板：查看 / 语义搜索 / 编辑 / 删除 / 置顶 / 导出 / 一键清空
- [x] 正文加密（Fernet），未配置密钥时明确提示「当前为明文」而非静默降级
- [x] 启动时向量库与 SQL 双向对账：清理孤儿向量、补建缺失索引
- [ ] 记忆衰减：久未命中且低价值的记忆自动归档

## M3 · 情绪自适应（已完成第一轮）

- [x] 情绪 → 主题色（8 类情绪各有独立配色）
- [x] 情绪 → 字体（族/字号/字重/字距：衬线=低沉、圆体=愉悦、等宽=焦虑、粗体=愤怒）
- [x] 情绪 → 布局（间距密度 / 圆角 / 气泡宽度）
- [x] 情绪 → framer-motion 动效（弹簧刚度与阻尼随情绪强弱变化）
- [x] 情绪 → Three.js 粒子壁纸（数量 / 速度 / 扰动 / 铺开四维随情绪变化）
- [x] Web Audio API 频谱驱动壁纸（低频 → 粒子大小与呼吸强度）
- [x] 情绪 → 音乐（按情绪关键词检索歌单，播放接入频谱）
- [x] 全链路优雅降级（WebGL 不可用退回 CSS Gradient；音乐服务未启动给启动指引）
- [ ] 情绪连续过渡（跨情绪插值而非跳变）
- [ ] 情绪 → 布局结构变化（如低落时收窄阅读区域）
